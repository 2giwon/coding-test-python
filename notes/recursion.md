# 재귀 체득 노트 (반드시 습득 — 코테 전 범위의 뼈대)

> 목적: 재귀를 "읽어서 아는 것"에서 "손이 기억하는 것"으로. 완전탐색·DFS·백트래킹·조합/순열·트리·분할정복이 전부 이 뼈대.
> 참조: 사고법은 치트시트 "재귀 = 계약으로 읽기"(python-cheatsheet.md). 이 문서는 **연습 커리큘럼**.
> 발단: 2026-07-21 모음사전 재풀이에서 재귀·product가 손에 안 잡혀 살짝 코드를 봄. 근본이 재귀라 판단 → 사다리 학습 등록.

## 1. 왜 어려운가 — 콜스택을 끝까지 따라가려 해서

머릿속으로 `dfs('A')→dfs('AA')→dfs('AAA')…`를 다 펼치면 3단만 가도 터진다. 인간 뇌는 그렇게 못 한다. 이게 재귀가 어려운 유일한 이유다.

## 2. 올바른 방법 — 믿음의 도약 (Leap of Faith)

**한 겹만 생각하고, 나머지는 "이미 잘 된다"고 믿는다.**

> "dfs(current)는 current로 시작하는 모든 경우를 알아서 다 처리한다고 믿는다.
> 그럼 나는 지금 current 하나만 처리하고, 자식들에게 나머지를 떠넘기면 끝."

증명하지 않는다. 믿는다.

## 3. 만능 템플릿 — 항상 이 3부분

```
def dfs(상태):
    if 종료조건:        # ① base case — 없으면 무한루프
        return
    처리(상태)           # ② 지금 이 순간 할 일 (담기/더하기/판정)
    for 선택 in 선택지:   # ③ 다음 단계로 떠넘기기 (재귀 호출)
        dfs(다음상태)
```

모음사전 대입: ① `len(current)>5: return` ② `dic.append(current)` ③ `for ch in "AEIOU": dfs(current+ch)`

## 4. 체득 루틴 (운동처럼 — 읽지 말고 쳐라)

**매일 아침 30초**: 빈 종이에 3줄 템플릿(종료→처리→for 재귀)을 **안 보고** 쓴다. 열흘이면 손에 붙는다.

**난이도 사다리 (하루 1개, 5분, 안 보고 재현될 때까지)**:

| 단계 | 문제 | 핵심 | 통과일 |
|:--:|--|--|:--:|
| 1 | `factorial(n) = n * factorial(n-1)` | 종료조건 + 믿음의 도약 (가장 순수) | |
| 2 | `sum_to(n) = 1+2+…+n` 재귀로 | 누적을 인자로 넘기기 | |
| 3 | 문자열 뒤집기 `reverse(s)` 재귀 | 문자열 쪼개기 (s[0] + reverse(s[1:])) | |
| 4 | 리스트 합/최댓값 재귀 | 리스트 재귀 | |
| 5 | 조합 생성 (모음사전류 `dfs(current)`) | for 안에서 재귀 = 완전탐색 | ✅ 07/21 (살짝 봄) |

1~2번은 쉬워 보여도 **믿음의 도약을 몸에 새기는 것**이 목적. 이게 되면 5번이 자연스러워진다.

**재풀이 편입**: 재귀 문제는 무조건 1주 후 재풀이 대상 (오답노트 시스템에 태운다).

## 5. 실전 함정 (치트시트에도 있음)

- 재귀 기본 한도 1000 → 깊으면 `sys.setrecursionlimit(10**6)`
- 문자열/튜플은 불변 → 새로 만들어 넘기면 상태 복원 불필요. 공유 리스트면 `append→재귀→pop`으로 복원(백트래킹)
- 종료조건 먼저 쓴다 (안 쓰면 무한 재귀 → RecursionError)
