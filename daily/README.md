## 왜 유형별 폴더를 쓰지 않나

`00-recursion-ladder` ~ `11-heap` 은 보존만 한다. 새 문제는 전부 이 폴더에 **날짜순**으로 쌓는다.

이유: **폴더 이름이 유형을 알려주는 것**이 기존 방식의 구조적 공백이었다.
2026-10-20 유형 식별 드릴에서 도구 2.5/8, 제약 조건을 근거로 쓴 문항 0/8 이 나왔고
진단이 "폴더가 유형을 알려준다. 실전에서는 모른다"였다. 날짜순으로 두면 그게 사라진다.
